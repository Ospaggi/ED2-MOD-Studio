# ED2 Mod Studio v0.8.1

한국 DOS판 **드래곤 슬레이어 영웅전설 II**용 통합 모드 도구입니다. Python 표준 라이브러리만 사용합니다.


## 실행

```bat
py -3 ed2_mod_studio.py C:\GAMES\ED2
```

게임 폴더를 생략하면 GUI에서 선택할 수 있습니다.

```bat
py -3 ed2_mod_studio.py
```

검사만 실행:

```bat
py -3 ed2_mod_studio.py C:\GAMES\ED2 --no-gui
```

분석 CSV/JSON 생성:

```bat
py -3 ed2_mod_studio.py C:\GAMES\ED2 --export-analysis analysis --no-gui
```

## 확정된 몬스터 주요 필드

```text
+0x03  몬스터 레벨  uint8
+0x04  현재 HP       uint16
+0x06  최대 HP       uint16
+0x0A  공격력        uint16
+0x0C  원시 EXP      uint16
+0x0E  원시 Gold     uint16
+0x10  방어력        uint16
+0x12  마법          uint16
+0x16  속도          uint8
+0x17  행운          uint8
```

속도와 행운은 더 이상 후보로 표시하지 않습니다. 값 범위는 원본 구조 그대로 `0~255`이며 도구가 임의의 게임 밸런스 제한을 추가하지 않습니다.

## EXP·Gold 오버플로 자동 방지

게임은 전투 중 EXP와 Gold를 16비트 누적 변수에 더합니다.

```text
누적 가능 범위: 0~65,535
```

이 값을 넘으면 원래 게임에서는 65,536 단위로 순환합니다. v0.8.1은 EXP 또는 Gold를 저장하기 전에 해당 DLL의 **활성 편성 몬스터**를 모두 계산합니다.

오버플로가 예상되면:

1. 사용자가 입력한 몬스터별 비율을 최대한 유지하고
2. 활성 편성의 보정 후 합계가 65,535 이하가 되도록
3. EXP 또는 Gold 원시값을 자동 축소합니다.

비활성 슬롯은 전투 누적 계산에서 제외하고 사용자가 입력한 값은 그대로 보존합니다.

### 자동 보호가 적용되는 경로

- 선택 몬스터 저장
- 전체 몬스터 일괄 수식
- 몬스터 CSV 가져오기

전체 검사에서도 이미 수정된 파일에 오버플로 위험이 남아 있으면 오류로 표시합니다.

## 사일런트 로드 8배 예시

원본 사일런트 로드는 활성 2마리 편성입니다.

```text
원시 EXP: 5001
원시 Gold: 2500
```

단순히 8배하면 EXP는 두 마리 합계가 65,535를 넘습니다. v0.8.1은 두 활성 몬스터를 거의 같은 비율로 자동 조정합니다.

검증 결과 예:

```text
요청 EXP: 40008 / 40008
자동 조정: 36409 / 36408
90% 보정 후 전투 합계: 65,535

요청 Gold: 20000 / 20000
90% 보정 후 전투 합계: 36,000
Gold는 안전하므로 조정 없음
```

## 편성 전체 보상 계산기

몬스터 탭에서 몬스터를 선택한 뒤 다음을 입력할 수 있습니다.

- 생존 파티 평균 레벨
- 생존 인원 1~4명

도구가 해당 DLL의 활성 편성 전체를 기준으로 다음을 표시합니다.

- 활성 몬스터 이름과 수
- 레벨 보정 후 EXP 합계
- 16비트 누적 결과
- 오버플로 여부
- 생존 인원별 캐릭터 1인당 EXP
- Gold 합계와 16비트 누적 결과

## EXP·Gold 계산 규칙

### 일반 전투

```text
보정값 = floor(원시값 × 90 / 100)
```

M_505 이전에는 파티 평균 레벨에 따라 `100 / 75 / 50 / 25 / 0%` 감쇠가 추가될 수 있습니다.

### M_505 이후

```text
90% 보정 적용
레벨 차이 감쇠 없음
```

### BGM 8 특수 전투

```text
90% 보정 없음
레벨 차이 감쇠 없음
원시값 그대로 사용
```

### EXP 파티 분배

```text
캐릭터 1인당 EXP
= ceil(16비트 전투 EXP 합계 / 생존 파티원 수)
```

Gold는 파티원 수로 나누지 않습니다.

## 전체 몬스터 일괄 수식

지원 예:

```text
+10
-20
*1.5
/2
=100
log10(x)*100
x + log2(x)*20
x + log1p(x)*50
sqrt(x)*30
```

대상:

```text
HP
Attack
Defense
Magic
Speed
Luck
EXP raw
Gold raw
```

EXP와 Gold는 수식 적용 후 편성 단위 오버플로 보호가 자동 실행됩니다.

## 기존 주요 기능

- 몬스터 377개 개별 편집
- 전투 그룹 드롭·확률·BGM·외형 참조 편집
- 일반 아이템 76개 편집
- 이벤트 아이템 100~126 이름 편집
- 마법 32개 편집
- AI 행동명과 전투 훅 표시
- 외형 BZH 내보내기·검증 교체
- 리소스 탐색기
- 별도 오디오 창의 MUS/INS/VGM 변환 기능

## 스크롤

모든 주요 목록과 상세 패널에 가로·세로 스크롤바가 있습니다.

```text
마우스 휠          세로 스크롤
Shift + 마우스 휠  가로 스크롤
```

## 백업과 안전성

- 최초 저장 시 `<파일명>.bak` 자동 생성
- 임시 파일 기록 후 원자적 교체
- MON DLL과 EXE 파일 크기 불변
- EXP·Gold 활성 편성 누적값 검사
- 드롭 확률과 데이터 범위 검사
- 외형 ID와 BZH 헤더 검사
- 코드 훅과 함수 포인터 읽기 전용
