# ED2 Mod Studio v0.8.2

한국 DOS판 **드래곤 슬레이어 영웅전설 II**용 통합 모드 도구입니다. Python 표준 라이브러리만 사용합니다.

이번 버전은 마법 편집 화면에 `MAGIC_BAIRITU`와 `MAGIC_CNT`의 실제 용도와 현재 값 해석을 추가했습니다.

## v0.8.2 핵심 변경

- `MAGIC_BAIRITU`를 마법 효과 배율로 표시 (`100`=기준 효과)
- `MAGIC_CNT`를 마법 재충전 주기로 표시
- 선택한 마법의 배율과 충전 속도를 상세 화면에서 실시간 해석
- `0x11`·`0x22`·`0x55`의 상대 속도와 `0` 니블 언더플로 위험 안내
- 몬스터 `속도`와 `행운` 필드를 확정 스탯으로 표시
- 몬스터 목록에도 속도·행운 열 추가
- EXP·Gold 전투 편성 합계의 16비트 오버플로 자동 방지
- 개별 몬스터 저장, 전체 일괄 수식, CSV 가져오기에 동일한 보호 로직 적용
- 실제 활성 편성 몬스터만 계산
- 전투 편성 전체 EXP·Gold 시뮬레이터 추가
- 생존 파티 평균 레벨과 생존 인원에 따른 실제 EXP 분배 표시
- M_505 이후 레벨 감쇠 해제와 BGM 8 특수 전투 반영
- 저장 전·전체 검사에서 보상 누적 오버플로 검사
- 기존 가로·세로 스크롤바, 아이템, 마법, AI·훅 기능 유지
- 사용 빈도가 낮은 M_501 전용 분석 탭 제거

## 마법 수치 설명

### MAGIC_BAIRITU

마법의 **효과 배율**입니다. 편집 화면에서는 bit7을 분리한 `0~127` 값을 표시합니다.

```text
100 = 기준 효과
25  = 기준 효과의 약 25%
127 = 기준 효과의 약 127%
```

원시 바이트의 bit7은 배율이 아니라 `MAGIC_SLC2` 보조 선택 플래그이며, 도구의 체크박스에서 별도로 편집합니다.

### MAGIC_CNT

마법 사용 후 다시 사용할 수 있게 되는 **재충전 주기**입니다. 16진수 입력을 권장합니다.

```text
상위 니블 = 반복 충전 주기
하위 니블 = 최초 충전 주기
```

두 니블이 같다면 값이 작을수록 빠릅니다.

```text
0x11 = 가장 빠른 안정 권장값
0x22 = 0x11보다 약 2배 느림
0x55 = 0x11보다 약 5배 느림
0x66 = 0x11보다 약 6배 느림
```

`0x00`, `0x01`, `0x10`처럼 어느 한 니블이 0인 값은 원본 감소 코드에서 언더플로가 발생할 수 있으므로 사용하지 않는 것이 안전합니다.

## 확정된 몬스터 주요 필드

```text
+0x03  몬스터 레벨  uint8
+0x04  현재 HP       uint16
+0x06  최대 HP       uint16
+0x0A  공격력        uint16
+0x0C  원시 EXP      uint16
+0x0E  원시 Gold     uint16
+0x10  방어력        uint16
+0x12  마법          uint16
+0x16  속도          uint8
+0x17  행운          uint8
```

속도와 행운은 더 이상 후보로 표시하지 않습니다. 값 범위는 원본 구조 그대로 `0~255`이며 도구가 임의의 게임 밸런스 제한을 추가하지 않습니다.

## EXP·Gold 오버플로 자동 방지

게임은 전투 중 EXP와 Gold를 16비트 누적 변수에 더합니다.

```text
누적 가능 범위: 0~65,535
```

이 값을 넘으면 원래 게임에서는 65,536 단위로 순환합니다. v0.8.1은 EXP 또는 Gold를 저장하기 전에 해당 DLL의 **활성 편성 몬스터**를 모두 계산합니다.

오버플로가 예상되면:

1. 사용자가 입력한 몬스터별 비율을 최대한 유지하고
2. 활성 편성의 보정 후 합계가 65,535 이하가 되도록
3. EXP 또는 Gold 원시값을 자동 축소합니다.

비활성 슬롯은 전투 누적 계산에서 제외하고 사용자가 입력한 값은 그대로 보존합니다.

### 자동 보호가 적용되는 경로

- 선택 몬스터 저장
- 전체 몬스터 일괄 수식
- 몬스터 CSV 가져오기

전체 검사에서도 이미 수정된 파일에 오버플로 위험이 남아 있으면 오류로 표시합니다.

## 사일런트 로드 8배 예시

원본 사일런트 로드는 활성 2마리 편성입니다.

```text
원시 EXP: 5001
원시 Gold: 2500
```

단순히 8배하면 EXP는 두 마리 합계가 65,535를 넘습니다. v0.8.1은 두 활성 몬스터를 거의 같은 비율로 자동 조정합니다.

검증 결과 예:

```text
요청 EXP: 40008 / 40008
자동 조정: 36409 / 36408
90% 보정 후 전투 합계: 65,535

요청 Gold: 20000 / 20000
90% 보정 후 전투 합계: 36,000
Gold는 안전하므로 조정 없음
```

## 편성 전체 보상 계산기

몬스터 탭에서 몬스터를 선택한 뒤 다음을 입력할 수 있습니다.

- 생존 파티 평균 레벨
- 생존 인원 1~4명

도구가 해당 DLL의 활성 편성 전체를 기준으로 다음을 표시합니다.

- 활성 몬스터 이름과 수
- 레벨 보정 후 EXP 합계
- 16비트 누적 결과
- 오버플로 여부
- 생존 인원별 캐릭터 1인당 EXP
- Gold 합계와 16비트 누적 결과

## EXP·Gold 계산 규칙

### 일반 전투

```text
보정값 = floor(원시값 × 90 / 100)
```

M_505 이전에는 파티 평균 레벨에 따라 `100 / 75 / 50 / 25 / 0%` 감쇠가 추가될 수 있습니다.

### M_505 이후

```text
90% 보정 적용
레벨 차이 감쇠 없음
```

### BGM 8 특수 전투

```text
90% 보정 없음
레벨 차이 감쇠 없음
원시값 그대로 사용
```

### EXP 파티 분배

```text
캐릭터 1인당 EXP
= ceil(16비트 전투 EXP 합계 / 생존 파티원 수)
```

Gold는 파티원 수로 나누지 않습니다.

## 전체 몬스터 일괄 수식

지원 예:

```text
+10
-20
*1.5
/2
=100
log10(x)*100
x + log2(x)*20
x + log1p(x)*50
sqrt(x)*30
```

대상:

```text
HP
Attack
Defense
Magic
Speed
Luck
EXP raw
Gold raw
```

EXP와 Gold는 수식 적용 후 편성 단위 오버플로 보호가 자동 실행됩니다.
